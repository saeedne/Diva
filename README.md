# جست‌وجوی آگهی دیوار

برنامه با Flask ساخته شده و امکان جست‌وجوی آگهی‌های عمومی دیوار، نمایش نتیجه‌ها در رابط فارسی و دریافت خروجی CSV یا Excel را دارد.

صفحهٔ اصلی فهرست شهرها و دسته‌بندی‌ها را دریافت می‌کند. دسته‌ها به‌صورت درخت بازشونده با چک‌باکس هستند و تا پنج انتخاب هم‌زمان می‌شود جست‌وجو کرد. برای هر آگهی، برنامه صفحهٔ عمومی جزئیات را می‌خواند؛ ستون‌های جدول و خروجی‌ها از مشخصات ثبت‌شده در آگهی‌ها ساخته می‌شوند، مثل رنگ و مدل برای وسیله یا متراژ و اتاق برای ملک. هرچه آگهی بیشتری انتخاب شود، دریافت جزئیات زمان بیشتری می‌برد.

## اجرا در ویندوز

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python flask_app.py
```

صفحهٔ برنامه: <http://127.0.0.1:8000/>

نمونهٔ API:

```text
http://127.0.0.1:8000/ads?url=https%3A%2F%2Fdivar.ir%2Fs%2Fmashhad%2Fbuy-residential&limit=50
```

مسیرهای برنامه:

- `/` رابط وب فارسی
- `/health` بررسی در دسترس بودن برنامه
- `/catalog` فهرست شهرها و دسته‌بندی‌ها
- `/ads` جست‌وجو و دریافت نتیجه‌ها به‌صورت JSON
- `/ads.csv` دریافت نتیجه‌ها به‌صورت CSV سازگار با Excel
- `/ads.xlsx` دریافت فایل Excel راست‌چین
- `/ads/<token>` دریافت اطلاعات عمومی یک آگهی

تعداد نتیجه بین ۱ تا ۱۰۰ است و در صورت حذف پارامتر، ۵۰ آگهی درخواست می‌شود.

فهرست دسته‌بندی‌ها از API رسمی اطلاعات پایهٔ کنار دیوار گرفته می‌شود. اگر endpoint آن کلید API بخواهد، متغیر محیطی `DIVAR_KENAR_API_KEY` را تنظیم کن. شهرها از فهرست عمومی خود دیوار می‌آیند.
