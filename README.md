# جست‌وجو و خروجی آگهی‌های دیوار

یک برنامهٔ محلی با Flask برای جست‌وجوی آگهی‌های عمومی دیوار، نمایش نتیجه‌ها در صفحهٔ فارسی و دریافت آن‌ها در قالب CSV یا Excel.

## قابلیت‌ها

- دریافت فهرست شهرها و دسته‌بندی‌ها از دیوار.
- ساخت لینک جست‌وجو با شهر، دسته‌بندی و عبارت دلخواه.
- فیلتر جست‌وجو بر اساس یک یا چند محلهٔ انتخاب‌شده در همان شهر.
- انتخاب حداکثر ۵ زیر‌دسته و دریافت بین ۱ تا ۱۰۰ آگهی.
- دنبال‌کردن صفحهٔ عمومی هر آگهی و خواندن مشخصات و امکاناتی که آگهی‌دهنده ثبت کرده است. عنوان ستون‌های مشخصات بر اساس اطلاعات آگهی‌ها ساخته می‌شود.
- نمایش لینک آگهی و لینک تصویر در صورت تأیید دیوار که تصویرها برای همان مورد هستند.
- دریافت نتیجه‌ها به‌صورت CSV یا فایل Excel راست‌چین با سطرهای سایه‌روشن و لینک‌های قابل کلیک.
- پاک‌شدن تیک دسته‌بندی‌ها پس از شروع جست‌وجو برای انتخاب بعدی؛ شهر و عبارت جست‌وجو باقی می‌مانند. خروجی CSV و Excel همچنان بر اساس جست‌وجوی انجام‌شده ساخته می‌شود.
- صفحهٔ جداگانهٔ تخمین قیمت ملک با انتخاب شهر، محله، نوع معامله و دستهٔ ملکی؛ برآورد با مقایسهٔ حداکثر ۵۰۰ آگهی تازه در بسته‌های ۵۰تایی و با درنظرگرفتن متراژ بنا، سال ساخت، زمین، طبقه، اتاق و امکانات انجام می‌شود. نتیجه، قیمت کل و قیمت هر متر و جدول آگهی‌های مشابه قابل چاپ را نشان می‌دهد.

مشخصاتی مثل متراژ، سال ساخت، تعداد خواب، رنگ یا مدل فقط وقتی در خروجی می‌آیند که در آگهی ثبت شده باشند. اطلاعات تماس خصوصی دریافت نمی‌شود.

## نصب و اجرا در ویندوز

در PowerShell، از پوشهٔ پروژه اجرا کن:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python flask_app.py
```

سپس صفحهٔ برنامه را در مرورگر باز کن:

<http://127.0.0.1:8000/>

برای توقف برنامه، در پنجرهٔ PowerShell کلید `Ctrl+C` را بزن.

## استفاده از صفحه

1. شهر را انتخاب کن و در صورت نیاز یک کلمه یا عبارت جست‌وجو بنویس.
2. زیر‌دسته‌های موردنظر را از فهرست بازشونده انتخاب کن. حداکثر ۵ دسته را می‌توان هم‌زمان انتخاب کرد.
3. تعداد آگهی را بین ۱ تا ۱۰۰ تعیین کن و «نمایش آگهی‌ها» را بزن.
4. نتیجه‌ها در صفحه نمایش داده می‌شوند. برای دریافت فایل، از دکمه‌های CSV یا Excel استفاده کن.

## مسیرهای برنامه

| مسیر | کاربرد |
| --- | --- |
| `/` | صفحهٔ جست‌وجوی فارسی |
| `/estimate` | صفحهٔ تخمین قیمت ملک |
| `/health` | بررسی در دسترس بودن برنامه |
| `/catalog` | فهرست شهرها و دسته‌بندی‌ها در قالب JSON |
| `/catalog/cities` | فهرست شهرها در قالب JSON |
| `/catalog/districts?city=<slug>` | فهرست محله‌های شهر انتخاب‌شده |
| `/ads` | دریافت نتیجه‌ها و ستون‌ها در قالب JSON |
| `/ads.csv` | دریافت نتیجه‌ها در قالب CSV سازگار با Excel |
| `/ads.xlsx` | دریافت فایل Excel |
| `/ads/<token>` | دریافت اطلاعات عمومی یک آگهی با شناسهٔ آن |
| `/estimate/property` | دریافت برآورد قیمت به‌صورت JSON با درخواست POST |

نمونهٔ جست‌وجوی JSON:

```text
http://127.0.0.1:8000/ads?url=https%3A%2F%2Fdivar.ir%2Fs%2Fmashhad%2Fbuy-residential&limit=50&query=%D8%A2%D9%BE%D8%A7%D8%B1%D8%AA%D9%85%D8%A7%D9%86
```

پارامتر `category` را می‌توان چندبار فرستاد؛ اگر ارسال نشود، دسته از مسیر `url` خوانده می‌شود. تعداد نتیجه باید بین ۱ تا ۱۰۰ و تعداد دسته‌ها حداکثر ۵ باشد.

برای تخمین، صفحهٔ `/estimate` را باز کن، شهر و مشخصات ملک را وارد کن و برآورد را بگیر. انتخاب محله اختیاری است؛ با انتخاب آن، آگهی‌های مقایسه‌ای از همان محله جست‌وجو می‌شوند. تعداد آگهی‌های بررسی‌شده قابل تنظیم و حداکثر ۵۰۰ است. نتیجه شامل بازهٔ تقریبی، قیمت هر متر، تعداد نمونه‌های قابل‌استفاده، سطح اطمینان و پیوند آگهی‌های مشابه است. هر آگهی، قیمت پیشنهادی فروشنده است؛ بنابراین برآورد قیمت معامله یا کارشناسی رسمی نیست.

## پیکربندی دسته‌بندی‌ها

فهرست شهرها از endpoint عمومی دیوار دریافت می‌شود. فهرست دسته‌بندی‌ها از API اطلاعات پایهٔ کنار دیوار خوانده می‌شود. اگر این API برای دریافت فهرست دسته‌ها خطای دسترسی داد، کلید API را در متغیر محیطی `DIVAR_KENAR_API_KEY` قرار بده و برنامه را دوباره اجرا کن:

```powershell
$env:DIVAR_KENAR_API_KEY = "کلید API"
python flask_app.py
```

## وابستگی‌ها

وابستگی‌های Python در `requirements.txt` قرار دارند: Flask، Requests و OpenPyXL.

## نکتهٔ فنی

جست‌وجو و دریافت جزئیات از endpointهای عمومی وب دیوار انجام می‌شود. این رابط رسمی و پایدار برای توسعه‌دهندگان نیست و ممکن است با تغییرات دیوار یا محدودیت شبکه موقتاً از دسترس خارج شود.
